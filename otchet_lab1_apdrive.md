## Тема работы

Разработка HTML/CSS-шаблона главной страницы автомобильного веб-сервиса.

## Цель работы

Целью лабораторной работы является получение практических навыков создания структуры веб-страницы с использованием HTML и её визуального оформления с помощью CSS. В рамках работы был разработан прототип главной страницы автомобильного маркетплейса, по функциональной идее похожего на популярные автомобильные площадки.

## Задание

Необходимо разработать начальный шаблон сайта автомобильной тематики с HTML-разметкой и CSS-стилями.

В качестве основных элементов страницы предусмотреть:

- шапку сайта и навигационное меню;
- блок поиска автомобиля;
- категории автомобилей;
- карточки популярных автомобилей;
- информационный блок с преимуществами сервиса;
- подвал сайта;
- адаптивное отображение страницы на разных размерах экрана.

## Структура проекта

Проект имеет следующую структуру:

Файл `index.html` содержит HTML-разметку главной страницы.

Файл `style.css` содержит все стили страницы и подключается к HTML-документу с помощью элемента:

```html
<link rel="stylesheet" href="style.css">
```

Такое разделение позволяет не смешивать структуру страницы и её оформление, а также упрощает дальнейшее редактирование проекта.

## Описание разработанной страницы

### 1. Шапка сайта

В верхней части страницы расположена шапка, содержащая:

- логотип апдрайв;
- навигационное меню;
- ссылку для авторизации;
- кнопку «Продать авто».

Шапка закреплена в верхней части окна браузера с помощью свойства `position: sticky`, поэтому она остаётся доступной при прокрутке страницы.

### 2. Главный блок

Главный блок страницы содержит заголовок:

> «Найди автомобиль своей мечты»

Под заголовком располагается краткое описание сервиса.

Основным элементом блока является форма поиска автомобиля. Она содержит поля:

- марка автомобиля;
- модель;
- цена.

Также предусмотрена кнопка поиска и ссылка на расширенный поиск.

### 3. Категории автомобилей

После главного блока расположена секция с категориями автомобилей.

В шаблоне предусмотрены следующие категории:

- легковые автомобили;
- кроссоверы;
- минивэны;
- коммерческие автомобили.

Каждая категория оформлена в виде отдельной карточки. В дальнейшем смайлики будут заменены на изображения.

### 4. Популярные автомобили

В отдельной секции отображаются карточки автомобилей.

Каждая карточка содержит:

- область изображения автомобиля;
- дополнительный бейдж;
- кнопку добавления в избранное;
- стоимость;
- название и год выпуска;
- технические характеристики;
- город и пробег.

В текущем варианте вместо фотографий автомобилей используются текстовые заглушки. В дальнейшем они будут заменены.

### 5. Блок преимуществ

На странице предусмотрен информационный блок с преимуществами сервиса.

В нём представлены:

- большой выбор автомобилей;
- проверка автомобилей;
- быстрый поиск.

Каждый пункт состоит из иконки, заголовка и описания.

### 6. Подвал сайта

В нижней части страницы расположен footer.

Он содержит:

- логотип;
- описание сервиса;
- ссылки для покупателей;
- ссылки для продавцов;
- информацию о компании;
- ссылки на политику конфиденциальности и пользовательское соглашение.

## Основные особенности CSS

Для создания единого визуального стиля в файле `style.css` используются CSS-переменные:

```css
:root {
    --primary: #e63946;
    --text: #17191c;
    --text-secondary: #73777d;
    --background: #ffffff;
    --background-gray: #f5f6f7;
    --border: #e3e5e8;
}
```

Это позволяет централизованно изменять основные цвета сайта.

Для построения сеток используются CSS Grid. Например, карточки автомобилей размещаются в четыре колонки:

```css
.cars-grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
}
```

Для отдельных элементов интерфейса используется Flexbox:

```css
.header__inner {
    display: flex;
    align-items: center;
    justify-content: space-between;
}
```

## Адаптивность

Для корректного отображения сайта на планшетах и мобильных устройствах используются медиазапросы `@media`.

При уменьшении ширины экрана:

- навигационное меню скрывается;
- количество колонок в сетках уменьшается;
- форма поиска перестраивается;
- карточки автомобилей переходят в одну колонку;
- элементы footer располагаются вертикально;
- изменяются размеры заголовков и отступов.

Таким образом, разработанный шаблон может использоваться как на компьютерах, так и на мобильных устройствах.
